## Расходы и секреты

Подробно: digest-setup.md. Нужны GitHub Secrets TILDA_MCP_TOKEN,
VERICO_LLM_API_KEY, VERICO_ARTIFACT_KEY. Не вводить в чат. Модель gpt-5.6-terra,
пример 50k input + 15k output + 5 search ≈ $0.33/выпуск; фактическая цена зависит
от токенов/источников. Четыре model-вызова и максимум пять поисковых ограничены;
жёсткого денежного лимита этот пример не устанавливает. Реальных API расходов
на LLM в этой задаче не было.
