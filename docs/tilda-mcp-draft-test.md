## Изученные инструменты и ограничения

| Инструмент | Параметры и поведение |
| --- | --- |
| `add_blank_page` | projectid, необязательный folderid; возвращает pageid; неидемпотентный |
| `get_pages` | projectid; использован до создания для поиска дубля и после для сравнения |
| `get_page_settings` | projectid + pageid; читать перед сохранением |
| `update_page_settings` | projectid + pageid + date (YYYY-MM-DD HH:MM), title, alias, meta_title, meta_descr и остальные сохраняемые поля; сохраняет целую форму, пропуски могут очищаться |
| `tpls_list` | query/category_id; подтвердил соответствие T123 → 131 |
| `add_record` | projectid + pageid + tplid, необязательные beforeid/afterid; неидемпотентный |
| `edit_record` | projectid + pageid + recordid + tab; читает поля и их точные имена |
| `update_record` | те же ID + tab + fields, optional only_field; перед записью обязательно прочитать тот же tab; для T123 поле code, only_field=code |
| `get_page_records` | projectid + pageid; подтвердил один T123 |
| `get_record_html` | projectid + pageid + recordid; для T123 вернул редакторское представление с экранированным исходным кодом |
| `publish_page` | projectid + pageid; создаёт публичную версию; только изучен, НЕ вызван |

Перед первым использованием прочитаны полные describe_tool для update_page_settings,
edit_record и update_record. При сохранении настроек новой страницы переданы
доступные сохраняемые поля из get_page_settings. Исходная дата сохранена с
точностью до минут, как требует инструмент. Backend нормализовал twitter_site
из пустого значения в `@`; существующих страниц это не касается.

T123 имеет nolivepreview=true: сохранение исходника подтверждено, выполнение
HTML на публичном сайте не тестировалось. Без отдельного разрешения страницу
не публиковать. Отдельное ограничение update_page_settings: загрузка cover/OG/
featured изображений этим инструментом пока не поддерживается; тест картинок
в эту задачу не входил.

Во время чтения/подключения наблюдались временные HTTP 502. Повторялись только
безопасные подключения/чтения. Создание страницы и добавление блока выполнены
однократно; повтор после неоднозначного write-timeout недопустим без сверки.
Локальная запись artifacts/tilda-draft-test.json предотвращает случайное
повторное создание в рамках этого теста, но не является production-хранилищем.
Автоматическая публикация по расписанию не включалась.
