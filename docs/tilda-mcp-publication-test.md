# Контролируемая публикация тестовой страницы VericoMedia

Дата отчёта: 28 октября 2026.

## Разрешение и границы

Пользователь разрешил опубликовать только страницу **340299609** проекта
**14191605**, slug `test-avtopublikacii-vericomedia`. Вызван один `publish_page`
с ровно этими двумя ID. Другие write-инструменты не вызывались. Существующее
расписание остаётся offline dry-run, автоматическая публикация не включалась.

## Проверка перед публикацией

- `get_projects` подтвердил проект «Галерея Маркетинга Верико» и vericomedia.ru.
- `get_page_settings` подтвердил ID, slug, название и SEO; published был пустым.
- `get_page_records`: один T123, tplid 131, recordid 5221527801.
- `edit_record` подтвердил точное совпадение с согласованным тестовым HTML:
  только section, h1 и p, без атрибутов, скриптов, ссылок, изображений и иных
  ресурсов. В исходнике только известные синтетические тексты: секретов и
  персональных данных нет. Содержимое перед публикацией не менялось.
- Сохранены снимки списка 93 страниц и настроек проекта для сравнения.

## Публикация и публичный результат

MCP вернул `publishonepage=yes`, projectid 14191605, pageid 340299609 и URL:

https://vericomedia.ru/test-avtopublikacii-vericomedia

- Публичный GET: **HTTP 200**, text/html; charset=UTF-8.
- Конечный URL совпадает, редиректа на другую страницу нет.
- Повторный MCP read подтвердил непустое published.
- `<title>`: «Тест автоматической публикации VericoMedia — техническая проверка».
- `<meta name="description">`: «Тестовая страница для проверки создания и редактирования через MCP Tilda. Не предназначена для публикации.»
- В публичном DOM заголовок и абзац T123 совпали с исходником и видимы.
- Исходный тестовый абзац содержит фразу «не опубликована»; он намеренно
  не переписывался при тесте публикации и теперь не описывает фактический статус.

## Браузерная проверка

Chromium 154, реальный публичный HTML и доступные ресурсы получены через
штатный HTTPS-прокси Python urllib с проверкой TLS и переданы Chromium через
request routing. Прямой Chromium получил ERR_CERT_AUTHORITY_INVALID от сертификата
прокси; ignore_https_errors и другие отключения проверки сертификатов не использовались.
Это проверка рендеринга полученной публичной страницы, не независимый end-to-end
тест сети Chromium или физического телефона.

| Viewport | Ширина документа | T123 видим | Горизонтальная прокрутка |
| --- | --- | --- | --- |
| 1440 × 1000 | 1440 | Да | Нет |
| 390 × 844 | 390 | Да | Нет |
| 320 × 740 | 320 | Да | Нет |

Скриншоты: `artifacts/tilda-publication/public-desktop.png`, `public-mobile.png`,
`public-mobile-small.png`. Видны заголовок, абзац, общая шапка/подвал.

Ограничения: внешние изображения/шрифты с neo.tildacdn.com, optim.tildacdn.com,
thb.tildacdn.com, static3.tildacdn.com и fonts.googleapis.com не загружались
использованным сетевым маршрутом; некоторые логотипы видны как незагруженные.
Внешние трекеры также не загружались. Поэтому подтверждена базовая адаптивность
самого тестового T123, но не полная визуальная идентичность всех глобальных
элементов сайта обычному браузеру. CSS/контент сайта для обхода ограничений не менялись.

## Проверка остальных страниц

Состав страниц не изменился относительно снимка непосредственно перед публикацией.
Для всех остальных 92 страниц записи `get_pages` совпали полностью, включая
published/changed. `get_project_settings` до и после совпали. Это проверка
метаданных и настроек; полный побайтовый аудит блоков всех 92 страниц не выполнялся.
Инструменты изменения навигации/настроек проекта не вызывались.

## Повторные запросы и хранение

`publish_page` вызван один раз, ответ успешный; ошибки 502 при самой публикации
не было. Публикация повторно не отправлялась. Локальный publish-once.claim
защищает от повторного запуска этого тестового скрипта; для production нужна
ранее описанная долговечная межзапусковая защита.

Секрет передавался только через предусмотренную переменную и прокси для tilda.ru.
В отчёте/скриншотах его нет. Сырые снимки сохранены в игнорируемой artifacts/;
этот отчёт содержит только результаты теста и идентификаторы разрешённой страницы.
